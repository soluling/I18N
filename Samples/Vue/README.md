# Soluling's Vue Samples

This directory contains Soluling's Vue samples. Learn about Vue localization from the [Vue localization guide](https://www.soluling.com/Guides/Vue) and the [Desktop documentation](https://www.soluling.com/Help/Vue/Index.htm).

| Sample         | Description                                                  | Notes                                                        |
| -------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| Driving        | A driving time calculator, before (`original`) and after (`vue-i18n`) internationalization with [Vue I18n](https://vue-i18n.intlify.dev). Vue 3. | Try this first! The sample of the guide.                     |
| vue-i18n\hello | A simple multilingual Hello World application using [Vue I18n](https://vue-i18n.intlify.dev). Vue 2. |                                                              |
| vue-i18n\sport | A localized application using [Vue I18n](https://vue-i18n.intlify.dev) and consuming a multilingual Sport API. Vue 2. | Learn more about the application from [here](https://www.soluling.com/Help/WebSample/Index.htm). |
| sport          | The same Sport API application. Vue 2.                       |                                                              |
